# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Specified by the user: React, TypeScript (strict), Vite, Tailwind CSS, React Router, IndexedDB, Vitest + React Testing Library, Playwright. No backend.

## Users
Designers, founders and small teams who need a brand typography system (and optionally an original display typeface) without paying for or learning heavy tooling. (Inferred from the phase brief; not interviewed.)

## Product Purpose
Tynovo (tagline: Shape your brand’s voice) is a free-first, browser-based tool with two connected modes: (1) Brand Typography System: pick existing fonts, define roles and type scales, preview brand applications, export documentation and code; (2) Custom Typeface Creator: generate original rule-based display typefaces, refine glyphs, validate quality, export genuine font files.

## Positioning
Local-first, no account, no backend, no AI service: projects live in the browser and exports are real files. One shared project model and token set connects system and custom-typeface work.

## Operating Context
Runs entirely in the browser. Projects persist in IndexedDB with explicit export/import for recovery. Includes a public marketing site and a separate application area in one repository.

## Capabilities and Constraints
- No mandatory account, backend, database, paid API or AI service in the initial release.
- Never fake font exports, metadata, quality scores, payment status or licensing guarantees.
- Never silently overwrite projects or discard unsaved changes.
- Generated-font licensing is kept separate from licensing of font-generation libraries and third-party fonts.
- Only original procedural designs and properly licensed fonts.
- Usable on desktop and tablet, practical on mobile.

## Brand Commitments
Binding visual constraints given by the user: Manrope as interface font; accent #C74504; primary text #444444; neutral white/light-grey surfaces, subtle borders, restrained shadows; modern, editorial, precise, minimal; specimens are the visual focus; prefer side panels and drawers over modals; avoid a generic AI-dashboard look.

## Evidence on Hand
No customers, testimonials, benchmarks, pricing or user numbers exist. None may be fabricated on the marketing site.

## Product Principles
1. Functional and lightweight over feature volume.
2. Claim only what is implemented and tested.
3. The user's work is never silently lost or overwritten.
4. One shared project model and token set across both modes.
5. Real artefacts: exports are genuine files.

## Accessibility & Inclusion
Accessible contrast, keyboard operability and visible focus throughout.
