# Brand Typography Studio

Free-first, browser-based studio with two connected modes: a **brand typography system** and a **custom typeface creator**. No account, backend, database, paid API or AI service. Projects live in your browser (IndexedDB) and can be exported as files.

> **Status: Phase 4 (glyph editing, export and quality validation).** Working: public website; project dashboard and autosaving workspace; type-scale preview; and the **Custom Typeface Creator**: three rule-based families (geometric, rounded, modular) generating 90 of 95 target ASCII characters, a **glyph editor** (point-level outline editing with guides, zoom and pan, undo and redo, keyboard operation, per-glyph overrides, reset to the generated shape), a **text preview** that shows the editor view next to the real exported file and compares them, **quality checks** with evidence and fixes (no score), font information (names, copyright, licence), seeded variations with restore points, honest coverage reporting, and **TrueType and OpenType/CFF export** that reads each finished file back and compares it with the design before offering it. Not built yet: font catalog, role editing, brand previews, token/code export, Bézier curve editing, WOFF/WOFF2. What was and was not tested in design applications is in `docs/font-export-validation.md`. The website labels every capability *Available now*, *Early version* or *In development* from one data file (`src/modules/marketing/content.ts`).
