# Brand Typography Studio

Free-first, browser-based studio with two connected modes: a **brand typography system** and a **custom typeface creator**. No account, backend, database, paid API or AI service. Projects live in your browser (IndexedDB) and can be exported as files.

> **Status: Phase 5 plus the Brand Typography System (Phase 2).** Phase 2 adds: brand direction (name, description, personality, use cases, tone, readability/display priorities), a 24-font OFL catalog built from font-package metadata with search, filters, weights, styles, licence and source, bounded on-demand loading with failure handling and honest availability, font pairing, add/remove roles, fallback stacks, heading and body sizes, fluid type scale with value checks, and a preview environment (website, editorial, product, poster; light/dark; phone/tablet/fit; saved sample text) that uses the same tokens as the exports (`docs/brand-typography-system.md`). Phase 5 added: roles that take your own typeface or an existing font (with measured fit checks), brand application previews that update with the typeface, a unified export centre (Markdown specification, CSS, DTCG tokens, HTML specimen, sources and licences, zip), project delete-with-backup, upgrade of older saved projects and recovery of damaged ones (`docs/integrated-workflow.md`). Earlier phases:  public website; project dashboard and autosaving workspace; type-scale preview; and the **Custom Typeface Creator**: three rule-based families (geometric, rounded, modular) generating 90 of 95 target ASCII characters, a **glyph editor** (point-level outline editing with guides, zoom and pan, undo and redo, keyboard operation, per-glyph overrides, reset to the generated shape), a **text preview** that shows the editor view next to the real exported file and compares them, **quality checks** with evidence and fixes (no score), font information (names, copyright, licence), seeded variations with restore points, honest coverage reporting, and **TrueType and OpenType/CFF export** that reads each finished file back and compares it with the design before offering it. Not built yet: Bézier curve editing, WOFF/WOFF2. What was and was not tested in design applications is in `docs/font-export-validation.md`. The website labels every capability *Available now*, *Early version* or *In development* from one data file (`src/modules/marketing/content.ts`).
